# Projet Federated Learning — Analyse clinique de la marche

Ce projet a pour objectif d’étudier l’utilisation de l’apprentissage fédéré pour classifier des données de marche clinique, notamment entre des sujets TD et CP.

Nous comparons deux approches : un entraînement centralisé, où toutes les données sont regroupées, et un entraînement fédéré avec Fed-BioMed, où les données sont réparties entre plusieurs clients simulant des hôpitaux.

L’objectif est d’évaluer si le Federated Learning permet d’obtenir des performances proches du modèle centralisé tout en gardant les données localement chez chaque client.
